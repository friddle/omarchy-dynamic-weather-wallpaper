Base Image

The reference photo AI builds upon. Its filename becomes the prefix of generated wallpapers. Click a photo to make it active, right-click to delete.

Click or drag an image here (jpg / png / webp, ≤30MB)
Describe a scene, let AI create a base image for you
e.g. westlake.jpg → westlake_rain_1216_20-25_springbegin.jpg
2

Reference Images

Character art or style samples sent with every AI request (multi-image image-to-image). Use {ref_names} in the prompt to reference them by name.

Click or drag reference images here (jpg / png / webp, ≤30MB, up to 4 sent per request)
3

AI Image Generation

Any OpenAI-compatible images API. With a base image it calls images/edits (image-to-image); without one it calls images/generations.

Candidates load from your API once Base URL & Key are set; free text allowed.
Any WxH your API supports; auto = provider default. Your monitor's native size gives the sharpest wallpaper.
Placeholders: {weather_name} {weather_cn} {weather} {temp} {temp_min} {temp_max} {period_name} {period} {solarterm_name} {solarterm} {city} {time} {ref_names} — English template recommended; Chinese works too.
Without an API key the base image is used directly (fallback mode).
1

Network Channel

Determines the default weather services. With auto, connectivity is checked at startup: international services are used when reachable, otherwise China-direct services.

2

Weather Source & City

Default sources are free and keyless. QWeather / OpenWeatherMap require a free API key (fields appear only when selected).

3

Target Displays

Select which displays the wallpaper applies to.

Click refresh to load displays
4

Schedule & Naming

Wallpaper filename pattern: base_weather_period_solarterm.jpg. Generated results are cached and reused until any checked condition changes.

Unchecked elements never trigger a new AI image. The calendar widget always re-renders on date change using the cached AI image — no regeneration.
5

Language

Interface language, also used by the {weather_name} and {solarterm_name} prompt placeholders.

Widgets Preview

The info widget and the calendar are composited onto the same wallpaper. Drag either box to set its position.

Drag either widget inside the preview to set its position; banner style is pinned to the bottom. Click ⤢ on a widget to enlarge.

Wallpaper Info Widget

Composite weather/temperature fields onto the wallpaper before it is applied. Rendered with ffmpeg (preinstalled on Omarchy).

Calendar Widget

Composite a month calendar onto the wallpaper — on the left by default (info widget stays on the right). Today is marked with a red heart.

Auto-generate Base Image

Describe the scene — AI creates a new base image (text-to-image) and sets it active. Requires the API key configured in AI section.

Local Access Token

This settings page is only for the current user. Launch it from the app to sign in automatically, or paste your local token once.

Token file: macOS ~/Library/Application Support/omarchy-dynamic-wallpaper/token · Linux ~/.config/omarchy-dynamic-wallpaper/token · Windows %APPDATA%\omarchy-dynamic-wallpaper\token — or run `python3 -m weatherwall serve` and copy the URL it prints.
